# 音乐与音频资产规范 (Audio Pipeline)

本目录归口管理项目全量背景音乐、环境音效与角色语音。

---

## 目录结构划分

- **`bgm/`**：游戏背景音乐与主旋律
  - 格式推荐：`.mp3` 或 `.ogg`，采用循环无缝切片（Seamless Loop）。
  - 码率控制：128kbps～192kbps 立体声，兼顾网络首屏极速加载。
- **`sfx/`**：即时交互音效
  - 包含：角色跳跃、击中反馈、拾取金币、技能释放、UI 点击、通关胜利与 Game Over。
  - 格式推荐：`.wav` 或 `.ogg`，单声道或轻量立体声，持续时间 0.2s～2s。
- **`voices/`**：角色台词与 NPC 语音
  - 可通过 MiniMax TTS API 批量生成，为游戏剧情注入生动性格。
  - 命名规范：`npc_<角色名>_<情境序号>.mp3`（例如 `npc_cyberpunk_merchant_greet_01.mp3`）。
