# 体验 polish · 第二轮

本轮只 polish 已有功能和画面，不加新玩法。目标：减少「第一次接触就卡住」的时刻，并让三个场景状态更一眼可读。

## 已记录的问题（来自上一轮截图复查与自测）

1. **没有声音时完全没有提示**：`AudioContext` 被浏览器拒绝或 MP3 解码失败时，`issue` 只写进 `audio.snapshot()`，玩家听不到任何反馈、也不知道可以点静音/刷新。
2. **追逐红框会在整局紧张时反复闪现**：`dangerUntil` 每次状态切换都重置为 1.2 秒，脱身与再被发现时重复弹「被发现了」，噪音大于信息。
3. **值班员进入「搜索」时没有任何空间反馈**：HUD 换成一句话，但地面上看不到它在找哪里，玩家不知道能否贴着走。
4. **安全门通电后 HUD 只变成「已通电」**，玩家仍需自己想往哪跑；小地图的东侧标记变化太细。
5. **1280 下顶部计时器与右侧工具条在某些宽度会贴太近**（1280 实测未重叠，但 1024 未验证）。
6. **暂停面板不显示本局进度**，玩家不知道该不该继续。

## 本轮计划

- 声音问题：启动后若 `issue` 非空，用一次简短提示条告知「声音不可用，游戏继续」；静音按钮保持可点击。
- 危险提示：只在「巡逻/搜索 → 追逐」的进入沿触发一次，持续到离开追逐；不再每次状态切换都重复。
- 搜索反馈：值班员进入搜索时，在地面加一个淡色搜索圈表示「最后已知位置」。
- 安全门：通电时同时在小地图与 HUD 用文字+颜色双通道提示「东侧 · 安全门已通电」。
- 暂停面板：显示剩余时间与已发动指令数。
- 全部改动后跑 `npm run test` / `npm run typecheck` / `npm run build`，并重新截图 1280 与 1920 复查。
