# 《查房》(Rounds)玩法速读

**一句话：**在医院躲开巡查的值班员，坚持 **45 秒**；安全门亮起后，跑到门口逃出去。

## 玩家要做什么

1. 沿着相通的走廊移动，利用墙、病床和柜子挡住值班员的视线。
2. 值班员看见你，或听见你在附近奔跑，就会追来。它比步行的你快；奔跑虽快，但体力有限、也会发出声音。
3. 在合适的时机用“值班指令”改变医院，争取绕路逃脱的机会。
4. 倒计时归零后，**亲自跑到亮起绿灯的安全门**才算赢；被值班员抓住就输，可以马上重开。

## 三条值班指令

| 按键 | 指令 | 对你有利 | 代价 |
|---|---|---|---|
| `1` | 全院开灯 | 看清出口路线和它所在的走廊 | 它也看得更远 |
| `2` | 封锁走廊 | 防火门落下，让它改道 | 你也不能穿过这扇门 |
| `3` | 广播查房 | 先躲开它的视线，再用广播把它引向病房 | 广播后它会搜得更仔细 |

## 操作

`WASD` 移动 · 按住 `Shift` 奔跑 · 鼠标右键拖动镜头 · `1/2/3` 使用指令 · `Esc` 暂停 · 结算后按 `R` 重开。

**一局的精彩时刻：**值班员发现你 → 你放下防火门 → 它被迫绕另一条走廊 → 你趁机冲向刚亮起的安全门。

**画面感觉：**明亮、干净、写实的医院；有一点被追赶的紧张感，不靠黑暗、血腥或突然吓人。
