## 《查房》(Rounds)怎样让别人一眼看懂

这部分是作品设计建议，不是官方比赛规则：

1. 开始画面只讲一句话：**“躲开值班员，活过 60 秒，安全门亮起后跑过去。”**
2. 操作提示只突出 **WASD 移动、Shift 奔跑、1/2/3 改写医院**；其余操作放次级说明。
3. 玩家第一次按指令时，让医院真实变化，并用一句短提示说明代价。例如：“封门成功——你也得绕路。”
4. 现场展示时，先请观众选 `1`、`2` 或 `3`，再当场执行；在一分钟内展示追逐、指令、逃生或失败。
5. 找一个没看过文档的人试玩。如果他要靠讲解才知道目标或看不出指令造成的变化，就继续改开场和反馈。
