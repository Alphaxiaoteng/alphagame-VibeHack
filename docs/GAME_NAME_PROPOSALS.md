## 先说结论

首选《查房 / Rounds》,备选《常规医嘱 / Standing Orders》。这两个名字都能同时指向医院制度和游戏机制,英文各只有一两个词,适合路演喊出和 Steam 商店页。以下命名我没有逐个核查 Steam 与商标重名,定稿前请先查一遍(尤其是 Rounds、Mains、On Call 这类通用词)。

## A. 冷峻制度与规训感

**A1《应急照明》 / Emergency Lighting**

- Tagline:建筑在运转,人不在预案里。
- 意象:这是消防规范里的正式术语,没有任何恐怖色彩。画面是冷白备用灯、绿色出口标识和一条没人规划过的逃生路线。情绪是制度仍在正常运转,而你不在它的预案里。
- 路演:开场不说话,直接把灯光切到冷白,再说名字。记忆锚点是游戏画面本身的光,名字等于美术风格。

**A2《交接班》 / Handover**

- Tagline:今晚没有人交代你。
- 意象:医院最日常的流程,也是责任最容易丢失的环节。官僚感来自"没人负责",不靠怪物。中文三个字有公文的节奏。
- 路演:一句"这一班,没人接你",再加上 60 秒倒计时。

## B. 极简悬疑与电影感

**B1《主电源》 / Mains**

- Tagline:The building is still working.
- 意象:只有一个技术名词,Playdead 式的冷淡。"Mains"指市电,玩家一听就知道电没了。留白很多,没有一个字解释剧情。
- 路演:黑屏,一声断电音效,然后说"Mains"。第一个音节很短,适合重复。

**B2《待机》 / Standby**

- Tagline:Sixty seconds to full power.
- 意象:设备待机、备用电源待命、你在等待,三层意思叠在一起。冷、克制,也有节奏。
- 路演:"待机"和"60 秒"形成对比,可以做成口号:待机,六十秒。

## C. 规则改写与时空压迫

**C1《常规医嘱》 / Standing Orders**

- Tagline:Rewrite the rules. Keep the cost.
- 意象:Standing order 在医院里指长期有效的医嘱,在军队和机构里指常设命令。三条值班指令正是这个概念,发出后无法撤销,代价也跟着留下。
- 路演:"你有三条医嘱,每一条都撤不回来。"这句话直接讲清机制。

**C2《直至复电》 / Until Restored**

- Tagline:Sixty seconds. Three orders. No undo.
- 意象:取自"供电恢复前"这类公告用语。名字本身就是一个倒计时,也暗示规则改写的代价会持续到最后。
- 路演:名字加数字三连:六十秒、三条指令、不可撤销。

## D. 双关语与哲学心理张力

**D1《查房》 / Rounds**

- Tagline:Someone is always making them.
- 意象:查房是医生巡视,也是保安巡逻,同时还有"一轮一轮"的循环感。玩家躲的是巡查,玩的是闭环走廊。一个词里同时有医疗、监视和循环。
- 路演:你的"广播查房"指令就是游戏名,可以让名字和机制在现场互相呼应。

**D2《留观》 / Under Observation**

- Tagline:Who is watching whom?
- 意象:"留观"是医院里让病人留下来观察的流程,在这里转成被监视。有制度的冷感,也有一点被审视的不安。
- 路演:反问句很适合现场互动:"谁在观察谁?"

**D3《值班》 / On Call**

- Tagline:You were never on the roster.
- 意象:值班本是职责,但玩家是那个不在排班表上的人。身份错位带来心理张力。
- 路演:"On Call"好念,但是通用词,重名风险最高。
