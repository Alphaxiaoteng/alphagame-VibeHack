# 《查房》3 分钟路演脚本

> 今日 18:00–20:00 现场路演，每组严格 3 分钟，观众与 Mentor 实时投票。本脚本按时间段写好话术与操作；上台前完整排练一次并计时。

## 一句话定位（背熟）

**"停电的医院里，你是被查房的值班对象。活过 45 秒，安全门通电跑过去就赢——而你手里有三条能改写医院规则的『值班指令』，每一条都有代价。"**

补一句降低门槛："无需安装，浏览器里直接玩，散场扫二维码就能试。"

## 上台前 2 分钟环境自检

- [ ] 笔记本插电、外放音量试过一次（脚步与广播是气氛核心）
- [ ] 浏览器预开两个标签：① `http://127.0.0.1:4174/?debug=1`（演示主标签）② `http://127.0.0.1:4174/`（备用正常入口）
- [ ] 退出聊天软件与系统通知，防焦点被抢
- [ ] 演示机全程用本地预览，不赌现场网络；另备 LAN 兜底：终端 A `npm run serve:lan`、终端 B `npm run qr:lan`
- [ ] 观众二维码物料就位（公网构建将在 17:00 冻结前更新为最新版）

## 分段脚本

### 0:00–0:20 开场

- 停在开始面板，念一句话定位。
- 点"开始值班"，边走边补一句操作："WASD 移动，Shift 奔跑，底部三张卡就是我的三条指令。"

### 0:20–1:20 指令段（核心互动）

- 对观众："现在你们来当值班员。1 开全院的灯，2 封走廊防火门，3 用病房广播把他引开——你们选哪条？"
- 按举手执行，执行瞬间念**代价话术**：
  - **1 开灯**："灯亮了——我看得清路线，但他也看得更远。"（画面：顶灯亮 + 地面出口箭头）
  - **2 封门**："防火门落下——他得绕路，我也一样。"（视觉最直观，冷场时默认演示这条）
  - **3 广播**："广播把他引去远端病房——但结束后他会警觉搜索。"
- 时间富余时快速追加一条指令演示。

### 1:20–2:10 追逐段

- 主动走进值班员视野触发追逐："他发现我了——红框、急促脚步。"
- 绕中央建筑墙角脱视野，指向地面搜索圈："他不透视——只去最后看见我的位置找我。"
- 若真被抓住："被抓即失败，R 重开——刚才那条指令本可以改写他的路线。"（顺势转回互动）

### 2:10–2:50 通电收尾

- 在演示标签按 **F4**（剩余时间设为 3 秒），倒数结束安全门绿灯亮："电来了，冲！"
- 按住 Shift 奔跑到东侧门口 → 胜利结算画面。
- 如被问及，说明：F4 仅是演示快进，完整 45 秒通关另有实录（见 IMPLEMENTATION_STATUS）。

### 2:50–3:00 收尾

- "这个游戏的核心就一句话：**改写规则、付出代价、重画路线**。扫码来试试，活过 45 秒就是自己人。"

## 突发预案

- **画面卡死**：F5 刷新，直接点"开始值班"跳到指令段（开场词已覆盖面板内容）。
- **网络问题**：演示机始终走本地预览；观众试玩引导到 LAN 二维码。
- **追逐失手被抓住**：转规则讲解话术（见追逐段）。
- **时间超支**：砍追逐段，直接 F4 通电收尾；**时间富余**：加演一条广播指令。

## 演讲人三不原则

不展开讲完整规则、每条指令只说一句代价；不念屏幕上的数字参数；最后 30 秒看观众、不看屏幕。
