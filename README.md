# alphagame-VibeHack

## 目录结构

- `assets/art/`：美术资产（模型 `models/`、贴图 `textures/`、参考图 `concepts/`、界面 `ui/`）
- `assets/audio/`：音频资产（背景音乐 `bgm/`、音效 `sfx/`、角色语音 `voices/`）
- `assets/prompts/`：资产生成与 LLM 提示词库
- `docs/`：设计方案与文档
- `src/`：业务源码
