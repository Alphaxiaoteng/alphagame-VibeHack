# 《查房》(Rounds)

> VibeHacks #06 (Vibe Coding for 3D 游戏世界) 参赛作品

**一句话定位**：在主电源中断的公立医院躲避巡查值班员，利用开灯、封门和广播三条临时“值班指令”改写路线，坚持存活 45 秒，再亲自抵达通电的安全门逃脱。

**当前状态**：可玩的离线功能 Demo。三条指令、巡逻/追逐/搜索、胜负、体力、暂停与重开已接通并做过浏览器操作验证；美术、难度平衡与陌生玩家体验仍需后续验收。详见 [IMPLEMENTATION_STATUS.md](IMPLEMENTATION_STATUS.md)。

## 安装与启动

需要 Node.js 22.12+（本机验证版本为 Node.js 24.21.0）和支持 WebGL 2 的桌面浏览器。

```bash
npm ci
npm run dev
```

开发入口：<http://localhost:5174/>。首次启动 Vite 可能把端口自动往后让；请以终端打印出的 `Local:` 地址为准。点击“开始值班”才推进计时并启用声音，无需 API Key 或登录。

验证正式构建：

```bash
npm run test
npm run typecheck
npm run build
npm run preview
```

正式构建入口：<http://127.0.0.1:4174/>。该端口固定且不允许被占用；若启动失败，先关闭占用 4174 的旧服务，不要把其他项目的页面当成游戏入口。不要直接双击 `index.html`，应通过 HTTP 服务访问。

## 游戏核心机制

- **目标**：存活 45 秒直至安全门通电亮起，亲自冲到门口获胜；被值班员碰到立即失败。
- **三条值班指令（改写规则，承受代价）**：
  1. `[1] 全院开灯`：看清出口路线与值班员走廊，代价是值班员视野同样扩大。
  2. `[2] 封锁走廊`：防火门落下阻断追捕通道，代价是玩家也无法穿过。
  3. `[3] 广播查房`：将病房灯光点亮引走值班员，代价是广播后值班员搜索范围与警觉度大幅提升。
- **操作方式**：`WASD` 相对镜头移动 · 按住 `Shift` 奔跑 · 鼠标右键拖动视角 · `1/2/3` 或点击卡片发动指令 · `Esc` / 暂停按钮暂停 · 结算后 `R` / “再来一次”重开。
- **手机 / 平板**：自动显示左下摇杆（拖动移动）、右侧「跑」与「暂停」按钮；底部三张指令卡可直接点。结算时按钮变「再来」。
- **体力**：连续奔跑约 3 秒耗尽，随后只能步行。松开 `Shift` 才能再次奔跑；步行或静止约 6 秒回满。
- **指令规则**：开灯 6 秒、封门 5 秒、广播 6 秒；每条成功发动后冷却 12 秒，一次只能执行一条主要效果。不能落门或被目视时发动广播，会给出拒绝原因且不扣冷却。
- **值班员**：无遮挡正面视野约 8 米 / 90°，开灯期间视距增至 12 米；7 米内能听见奔跑。丢失目标后前往最后已知位置搜索，不透墙读取玩家坐标。广播未被目视打断时，结束后在病房警觉搜索 6 秒。
- **暂停**：真实切到其他标签页超过约半秒会自动暂停计时、AI 与声音，并清空按键；回到前台必须点“继续值班”。瞬间的可见性抖动与窗口失焦不会冻结一局。

## 本地语音与素材

8 条中文语音已生成并放在 `assets/audio/voices/`，会随 `dist/` 打包。浏览器只播放本地 MP3，不会调用在线 TTS。

需要重新生成时，在装有中文音色和 `ffmpeg` / `ffprobe` 的 macOS 上运行：

```bash
npm run gen:voices
# 明确需要覆盖已有语音时：
npm run gen:voices -- --force
```

生成工具：macOS `/usr/bin/say`，中文 Flo / Eddy 音色；带通滤波后转为 44.1 kHz 单声道 MP3。医院模型与程序化材质由项目代码创建，未接入外部模型或在线贴图。商业发布前应单独核实所用系统音色的许可。

## 验收模式

仅在 <http://127.0.0.1:4174/?debug=1> 开放测试控制：

- `F2` / `F3`：切换北 / 南防火门；门框被占用时拒绝关闭，两门不能同时关闭。
- `F4`：剩余时间设为 3 秒。
- `F5`：立即通电，但仍须到门口才能胜利。

不带参数的入口不挂载调试句柄，功能键也不会快进。完整 45 秒试玩另行验证，不把调试快进当作正式通关证据。

## 部署与已知限制

- 构建使用 `base: './'`，可部署到子路径；本次没有执行 `deploy`、Git 提交或推送，公网地址不代表本次最新版。
- `npm run serve:lan` 与 `npm run qr:lan` 是已有局域网展示工具。手机可用摇杆与屏上按钮游玩，竖屏与横屏均已适配（横屏下开始面板内滚动、指令卡贴底边，旋转画面自动跟随）；仍只在 Chromium 触控模拟下验证过，未在真实 iPhone / Android 上试。
- 当前是功能 Demo，不是最终美术交付；真人陌生玩家试玩、长时间难度平衡和多设备性能验收未完成。
- 构建拆为业务入口约 61 kB（gzip 22 kB）与 three.js 约 572 kB（gzip 143 kB）两块，无体积告警；three 可被浏览器长缓存。无头环境下实测约 30 fps，未取得真实笔记本 60 fps 证据。
- 给同事的 5 分钟试玩步骤：[docs/PLAYER_PLAYTEST.md](docs/PLAYER_PLAYTEST.md)。

## 技术架构

- **渲染**：Three.js + TypeScript + Vite，桌面 WebGL 2 单页。
- **玩法**：独立纯逻辑模块，地图碰撞与 A* 导航共用定义；值班员使用本地感知状态机，不依赖语言模型或联网。
- **音频**：本地 TTS MP3 + Web Audio 短音效；追逐时脚步加密并叠加紧张铃，节奏基于游玩时钟而非帧计数。
- **验证**：Vitest 行为测试 + 类型检查 + 正式构建 + 浏览器键鼠试玩。
